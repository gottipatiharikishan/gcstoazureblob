9. WHY PUBSUB MUST BE ENABLED BEFORE INITIAL SYNC
================================================================================

Example

Migration Duration

10 Days

Day 2
1000 Files Uploaded

Day 5
500 Files Deleted

Day 8
300 Files Modified

If Pub/Sub starts after copy completes:

All changes are lost.

Correct Design

Day 0

Enable Notifications
Enable Pub/Sub
Start Migration

Result

Every change is captured.
